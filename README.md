# FSDH Mobile App

A Flutter-based mobile banking application prototype developed for FSDH, showcasing the user experience from the splash screen through onboarding and authentication.

## Overview

This project demonstrates the design and implementation of a modern mobile banking interface using Flutter and Dart.

The application focuses on creating a smooth, structured authentication experience while translating the FSDH mobile app design into functional Flutter screens.

## Features

- Splash screen
- Onboarding experience
- Login interface
- Sign-up/authentication flow
- Mobile-first responsive UI
- Custom Flutter widgets
- Screen-to-screen navigation
- Form-based user interaction
- FSDH-inspired visual design

## Tech Stack

- **Flutter** — Mobile application framework
- **Dart** — Programming language
- **Material Design** — UI components and design system
- **Git & GitHub** — Version control and project management

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Flutter SDK
- Dart SDK
- Android Studio or Xcode
- Android emulator, iOS simulator, or a physical device

### Installation

Clone the repository:

```bash
git clone https://github.com/3nylar/fsdh_app.git
```

Navigate into the project:

```bash
cd fsdh_app
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```

## Development

Check that Flutter is correctly configured:

```bash
flutter doctor
```

Analyze the project:

```bash
flutter analyze
```

Run tests:

```bash
flutter test
```
